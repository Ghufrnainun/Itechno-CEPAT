# Context — ITechno Cup 2026 Web Development

## 1. Ringkasan Kompetisi

**Tema besar:** "Adaptive Innovation for a Future-Ready Digital Society"
**Subtema:** "Smart Sustainable Digital Solution for Inclusive Society"

Solusi web harus align ke minimal 1 dari 4 SDG berikut:
- SDG 7 — Energi Bersih dan Terjangkau
- SDG 8 — Pekerjaan Layak dan Pertumbuhan Ekonomi

## 2. Syarat & Ketentuan Utama

- Peserta: mahasiswa aktif (Diploma/Sarjana), tim 2–3 orang, maksimal 1 karya per tim.
- Karya harus **orisinal** — belum dipublikasikan komersial, belum pernah menang kompetisi serupa.
- **Dilarang** pakai template instan (WordPress, Wix, dsb).
- Boleh pakai library/framework (React.js, Next.js, dsb) asal didefinisikan peruntukannya di dokumentasi.
- Boleh pakai AI, dengan catatan: digunakan etis, jaga privasi data pengguna, tidak ada celah keamanan, bebas pelanggaran hak cipta — dan wajib didokumentasikan.
- Identitas peserta tidak boleh digantikan pihak lain selama lomba berlangsung.

Submit: link repo GitHub (source code) + link hasil deploy/hosting (disarankan Netlify/Vercel).

Repo wajib berisi README.md/dokumentasi mencakup:
1. Penjelasan aplikasi (latar belakang & tujuan)

Format README wajib mengikuti template resmi ITechno Cup (Template README.md - ITECHNO CUP).

# Konteks Proyek Tim

## Tim
3 orang, pembagian peran umum yang disepakati:
- **Frontend & UI/UX**: bangun antarmuka, komponen interaktif, responsivitas.
- **Backend & Core Logic**: API, database, algoritma inti (matching/scoring engine).
- **Integrasi, DevOps & Dokumentasi**: realtime feature, deployment, README, materi pitching.

## Ide Terpilih: "KerjaMicro / SkillTukar"

**Subtema SDG:** SDG 8 — Pekerjaan Layak dan Pertumbuhan Ekonomi

**Target user:** Mahasiswa & UMKM lokal perkotaan.

**Masalah nyata:**
Mahasiswa butuh penghasilan tambahan tapi kesulitan kerja part-time terikat karena jadwal kuliah tidak menentu. Di sisi lain, UMKM lokal atau sesama mahasiswa sering butuh bantuan micro-task dadakan (contoh: foto produk, entry data, jaga booth sementara).

**Konsep aplikasi:**
Platform micro-freelancing & skill exchange berbasis lokasi, dengan radius pencarian terdekat (contoh: maksimal 2 km dari posisi user).

## Catatan Strategis dari Diskusi Sebelumnya

- Prioritas penilaian penyisihan ada di Tema&Subtema + Inovasi (total 40%) — narasi SDG & diferensiasi harus kuat sejak awal proposal, bukan ditempel belakangan.
- Dokumentasi (README sesuai template resmi) jangan dikerjakan mepet deadline — assign PIC dari awal.
- Jika menggunakan AI dalam pengembangan, wajib didokumentasikan penggunaan & pertimbangan etis/keamanannya di README.
